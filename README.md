# Anime Japanese Journey

A language training app for japanese that prepares you for watching a chosen anime. 

The main menu should be sorted first by added anime and then show the seasons and then episodes. It will process episodes one by one on demand. This includes automatically finding the japanese subtitles for the episode and creating flash cards. It needs to keep track on the users skills and guess which words or expressions the user already knows
